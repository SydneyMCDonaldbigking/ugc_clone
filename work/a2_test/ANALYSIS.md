# ANALYSIS — ref_video_2(纽仕兰纯牛奶开箱口播,18.67s)

整条片为什么有效。本文件把原片的事实和我们的解读分开写;时间点在 `TIMELINE.md`,
逐词时间在 `words.json`。**这里的一切只用来理解原片,不把原片画面交给任何生成模型。**

## 它想让观众得到什么

让观众得出结论:"这奶很好,而且我现在买很划算。"整条片没有明说"快去买",没有下单引导;
结论是观众自己推出来的。

## 情绪弧线

| 段 | 情绪 | 作用 |
|---|---|---|
| 0–2.3s | 调侃、分享家事 | 用"老公以为我发财了"暗示这奶贵、是好东西,但不用自己夸 |
| 2.3–3.2s | 压低声音、说悄悄话 | "他不知道":把观众拉进秘密,和老公站在对立面 |
| 3.2–9.2s | 兴奋揭晓 | 品牌 → 一箱多少 → "你去看看这啥价":贵的印象被"划算"反转 |
| 9.2–15.6s | 认真科普 | 从"便宜"转到"值":稀缺(要找代购)+ 权威数字(全球 1% 奶牛) |
| 15.6–18.7s | 满足地证明 | 倒奶进杯,同时报蛋白质数字,数字和画面同时落下 |

解读:前半段卖"划算",后半段卖"好"。先让观众觉得"贵的东西居然不贵",再给理由证明它确实值。
顺序不能反:先讲成分会像广告,先讲家事就像朋友聊天。

## 各个元素在做什么

- **A-roll(主画面)**:同一个人,正面中景,几乎全程对镜头说话。跳剪只用来剪掉停顿,不换机位。
  这些跳剪让节奏很快(约 7 字/秒),但画面始终是同一个"朋友在跟你说"
- **两个插入镜头**,都在给新信息:
  - 6.73s 俯拍打开的整箱:把"一箱 24 瓶"从一句话变成看得见的量
  - 9.30s 手持两盒特写,背景是黄色花枝(换了地方):产品"正脸"唯一一次清晰亮相,落在"他家的奶"上
- **贯穿全片的道具:桌上叠着的整箱**。从第一秒到最后一秒都在画面里,一直在无声地强调"量"。
  12.3s 以后多了一把红剪刀,之后一直留在桌上
- **动作和台词的对齐**:说品牌时手拍在箱子印的品牌上;说"到手 24 瓶"时掀开箱盖;
  说蛋白质数字时奶正在倒进杯子。每个卖点都有一个"手上的动作"作为证据
- **字幕**:白字黑边,画面下方居中,一句一换,和说话同步
- **声音**:背景音乐很重、很满(平均 -5.4dB),人声贴在音乐上面,整体很吵、很有"直播间"感
- **水印**:右上角"抖音@方脸小妹",随画面漂移(原片平台元素,不属于创意)

## 改编时要保留的作用(不是形式)

1. 开头用"别人的误会"间接暗示产品好,不自夸
2. "他不知道"这一拍的悄悄话语气:把观众拉到自己这边
3. 先"划算"后"值得"的顺序
4. 每个卖点配一个手上的证据动作,数字和动作同时落下
5. 桌上一直有东西在强调量
6. 两个插入镜头的作用:一个给"量",一个给产品"正脸"

## 已知不能照搬的(见 `product.en.json` 的 forbidden_claims)

"贵的奶"、"来抖音搞活动"、"要找代购才能买到"、"全球 1% 奶牛"、"4.0 克":
这些是原片针对纽仕兰的说法,我们的商品没有证据,作用保留、内容换成背标上的真实信息。
